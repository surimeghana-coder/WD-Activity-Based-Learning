# Borcelle Café — Restaurant Website

A simple restaurant website built with **HTML5** and **CSS3**. The page introduces Borcelle Café, highlights popular dishes, presents cuisines from around the world, and lists the latest fusion dishes.

## Features

- **Header section** with the restaurant name and welcome message.
- **Navigation menu** with links to Home, Dishes, Cuisines, and Contact.
- **About section** describing the restaurant.
- **Our Dishes** section featuring Spaghetti and Fusion Dosa.
- **Cuisines section** describing Italian, Indian, Chinese, Mexican, and Japanese cuisine.
- **Latest Dishes section** highlighting Korean-Style Spicy Paneer, Tandoori Momos, Butter Chicken Pizza, and Paneer Tikka Tacos.
- **Contact footer** with an email address and phone number placeholder.
- **Styling and hover effects** using a warm cream, brown, and orange color palette.

## Technologies Used

- HTML5
- CSS3

## Project Files

Keep the HTML file and stylesheet in the same project folder. The stylesheet is named `act18.css`.

```text
restaurant-website/
├── index.html       # Rename or replace with your actual HTML filename
├── act18.css        # Website styling
└── act18.md         # Project documentation
```

> If your HTML file has a different name, use that actual filename instead of `index.html` in the project structure above.

## How to Run

1. Save the HTML as your chosen HTML filename (for example, `index.html`).
2. Keep `act18.css` in the same folder as the HTML file.
3. Open the HTML file in a web browser.

## Customization Notes

- Replace the example contact details with the restaurant's real email address and phone number before publishing.
- Review spelling and naming throughout the page (for example, “Borcelle Café,” “Spaghetti,” and “Cuisines”) for consistency.
- The HTML currently contains inline styles as well as a link to `act18.css`; styles in the HTML may override or interact with the external stylesheet.
- The cuisine descriptions are informational. The page does not currently include online ordering, table reservations, or a backend contact system.
