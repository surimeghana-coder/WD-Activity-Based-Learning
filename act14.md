# Healthy Bites | Food & Nutrition

Healthy Bites is a responsive food and nutrition website built with **HTML5** and **CSS3**. It shares healthy food categories, simple recipes, an example daily meal plan, and practical healthy-eating tips.

## Features

- **Navigation bar:** Quick links to Home, Recipes, Meal Plans, Nutrition, and Tips.
- **Hero section:** Introductory message and a button linking to the recipes section.
- **Healthy food categories:** Information cards for vegetables, fresh fruits, protein foods, and whole grains.
- **Healthy recipes:** Example recipes with ingredients, preparation steps, and estimated calories.
- **Daily meal plan:** An example schedule covering breakfast, snacks, lunch, and dinner.
- **Healthy eating tips:** Simple suggestions for hydration, food variety, whole grains, salt, sugar, portion sizes, and physical activity.
- **Responsive layout:** Grid layouts adapt to different screen widths.
- **Interactive styling:** Hover effects, smooth scrolling, and styled content cards.

## Technologies Used

- **HTML5** — structures the website content.
- **CSS3** — styles the layout, colors, cards, navigation, and responsive design.

No JavaScript or external libraries are required.

## Project Structure

```text
healthy-bites/
├── index.html
├── act14.css
└── README.md
```

Make sure the HTML file links to the stylesheet with:

```html
<link rel="stylesheet" href="act14.css">
```

If your HTML file has a different filename, you can keep that name; just ensure it is in the same project folder as `act14.css`.

## How to Run the Project

1. Download or clone the repository.
2. Keep the HTML file, `act14.css`, and `README.md` in the same folder.
3. Open the HTML file in any modern web browser.

You can also open the folder in Visual Studio Code and use a local preview extension.

## Important Notes

- Calorie values shown in the recipes are estimates and may vary depending on ingredients, portion sizes, and preparation methods.
- The meal plan is an example and may not suit everyone's individual nutritional needs.
- This project provides general food and nutrition information and is not a substitute for personalized medical or dietary advice.
