# NRI IT [DTBU] College Website

A responsive college website created using **HTML5** and **CSS3**. The website presents college information, showcases courses, highlights admission news, and includes a student registration form.

## Features

- **Hero section:** College heading, tagline, and a button to explore courses.
- **Navigation bar:** Links to the Home, About Us, Courses, Registration, and Contact sections.
- **Welcome section:** Introduction to the college website.
- **About section:** College overview, information cards, and mission statement.
- **Courses section:** Course cards covering engineering, computing, science, management, and other study areas.
- **Latest news section:** Admission announcement and a link to the registration form.
- **Student registration form:** Fields for personal details, skills, preferred course, and feedback.
- **Responsive layout:** Grid layouts adapt to tablet and mobile screen sizes.
- **Interactive styling:** Hover effects, smooth scrolling, focus indicators, and styled form controls.
- **Accessibility considerations:** Labels for form fields and reduced-motion support.

## Technologies Used

- **HTML5** — website structure and content.
- **CSS3** — layout, colors, typography, responsive design, and visual effects.

No JavaScript or external libraries are required for the current design.

## How to Run Locally

1. Download or clone this repository.
2. Keep `index.html` and `act2.css` in the same folder.
3. Open `index.html` in a web browser.

You can also open the project folder in Visual Studio Code and use a local preview extension if you prefer.

## Registration Form Note

The registration form is currently a **front-end demonstration**. Its HTML uses `action="#"` and does not connect to a server or database, so submitted details are not saved or processed by a registration system.

Before using it for real registrations, connect it to a secure backend and implement appropriate validation and data protection. Do not collect real passwords through this demonstration form.

## Customization

- Edit the text and course details in `index.html`.
- Update colors, spacing, typography, and responsive breakpoints in `act2.css`.
- Verify college details, course availability, and admission announcements before publishing the website.
